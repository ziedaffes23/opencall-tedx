# TEDx Thyna Youth — Design reference

Cette référence décrit la direction visuelle livrée pour le formulaire Open Call.

| Élément | Décision livrée |
|---|---|
| Palette | Noir profond `#171717`, rouge TEDx accent `#e62b28`, ivoire `#f5f3ef`, gris papier `#eeece7` |
| Typographie | DM Sans pour l’interface, DM Mono pour les métadonnées, Playfair Display italic pour les phrases éditoriales |
| Composition | Hero asymétrique noir/rouge, blocs éditoriaux en pleine largeur, formulaire en grille avec colonne de repères numérotés |
| Forme | Angles diagonaux, cercles concentriques, symbole `×`, lignes fines et champs soulignés |
| Ton | Direct, curieux, humain et orienté vers la prise de parole des jeunes |
| Responsive | Navigation compacte sur mobile, empilement des champs, hero redimensionné et sections conservant la hiérarchie éditoriale |

Les captures de prévisualisation desktop et mobile constituent la vérification visuelle de cette référence. La composition est volontairement spécifique au contexte TEDx Thyna Youth et ne dépend pas d’un asset externe.
